# Requirements
  - [Latest version of Neovim](https://github.com/neovim/neovim/blob/master/BUILD.md)
  - [Installed and enabled Nerd Font in terminal](https://www.nerdfonts.com/)
  - ``tree-sitter-cli`` installed
  - ``curl`` or similar in your PATH
  - ``gcc`` compiler in your PATH
  - LSP installed for example ``clangd`` for C++
# Installation

```
curl https://github.com/kost052/neovim-config/blob/main/init.lua -o ~/.config/nvim
```
