# Requirements
  - [Latest version of Neovim](https://github.com/neovim/neovim/blob/master/BUILD.md)
  - [Installed and enabled Nerd Font in terminal](https://www.nerdfonts.com/) for the icons to work
  - ``tree-sitter-cli`` installed
  - ``curl`` or similar in your PATH
  - ``gcc`` compiler in your PATH
  - LSP installed for example ``clangd`` for C++
# Installation
Install latest version of Neovim and run the command below:
```
curl --create-dirs https://raw.githubusercontent.com/kost052/neovim-config/refs/heads/main/init.lua -o ~/.config/nvim/init.lua
```
